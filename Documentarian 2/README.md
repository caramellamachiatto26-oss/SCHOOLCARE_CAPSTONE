The Cost-Benefit Analysis evaluates whether implementing the SCHOOLCARE+: Web-Based School Clinic Records and Inventory Management System is more beneficial than the existing manual system. The current process relies on paper records, Microsoft Excel, and Google Sheets, which are inexpensive but time-consuming, prone to human errors, and make retrieving records difficult.

The proposed system requires a one-time development investment and ongoing maintenance costs. However, it provides significant benefits, including digital record management, real-time inventory tracking, automated report generation, improved data accuracy, secure storage through user authentication, reduced paperwork, and faster access to student health records.

The financial analysis consists of three tables:

Table 1: The current manual system costs approximately ₱4,300 per month or ₱51,600 annually, mainly for paper, printer supplies, office materials, and electricity. Although the cost is lower, the manual process becomes inefficient as records increase.
Table 2: The proposed system has a one-time development cost of ₱243,600 (about ₱40,600 per month for six months). Most of the budget is allocated to developer salaries, system development, testing, cloud hosting, and implementation.
Table 3: After implementation, the system has an estimated operating cost of ₱10,600 per month or ₱127,200 annually, covering maintenance, cloud hosting, software licenses, testing, and minimal printing expenses.

Although the proposed system has higher development and operational costs than the manual system, it offers long-term advantages through increased efficiency, improved security, reduced paperwork, better inventory management, and more reliable clinic operations.
